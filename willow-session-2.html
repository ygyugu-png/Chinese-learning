句型 Four useful patterns

跟……差不多

A is about the same as B.

北京的汽车跟伦敦差不多。

真没想到……

I really didn’t expect…

真没想到北京有这么多汽车。

A是A，可是……

Concede one point, then contrast.

贵是贵，可是交通好多了。

这还差不多

That’s more like it / fair enough.

出租车不用交？这还差不多。

    辩论 Congestion charge debate

    同意 For

    • 收进城费以后，开车的人会少很多。
    • 交通好了，空气也会好一点儿。
    • 贵是贵，可是我们可以坐公共汽车或者骑自行车。

    不同意 Against

    • 进城费太贵了。
    • 住在郊区的人有时候只能开车。
    • 公共汽车太挤了，地铁也常常晚点。
