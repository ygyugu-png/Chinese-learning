看图说话 Picture talk

Use the prompts to describe an airport/taxi scene.

Level 1: 她在哪儿？她有多少行李？

Level 2: 她为什么有点儿着急？司机看起来怎么样？

是……的 Past-event focus

Use 是……的 when the event is already known and you want to focus on when, where or how it happened.

你是在哪儿出生的？

我是在法国长大的。

她是坐飞机来的。

Negative: 我不是坐飞机来的，是坐火车来的。
